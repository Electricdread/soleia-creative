# Vault is the source of truth for agents

**Decision:** All direction to AI agents (what to build, priorities, decisions) lives in this vault. Agents read it before working and report back into `07 Agent Reports`.

**Why:** One place the CEO can write from the iPad; no re-explaining context every session.

**Not doing instead:** Re-typing context into each chat.

**Revisit if:** It stops getting used.
