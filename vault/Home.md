## Where things go
| Folder | What goes in it |
|---|---|
| [[00 Inbox]] | Anything, fast. Sort it later (or ask an agent to). |
| [[01 Briefs]] | One note = one job for an agent. Set `status: ready` when it's good to go. |
| [[02 Decisions]] | Calls you've made, and why. Agents treat these as rules. |
| [[03 Projects]] | One note per project: goal, status, links. |
| [[04 Knowledge]] | Facts that don't change much: venue, clients, brand, pricing logic. |
| [[05 Meetings]] | Meeting notes. |

## How to give an agent a job
1. New note from template **Brief** (command palette → *Templates: Insert template*).
2. Fill in **Goal**, **Why**, **Done when**.
3. Set `status: ready`, then sync (see [[iPad Setup Guide]]).
4. Start a Claude session on soleia-creative and say: **"Work the ready briefs."**
5. Read the result in [[07 Agent Reports]].
