# Soleia Creative App

## Goal
The client-facing app for Soleia: proposals, creative sessions, the Creative Guide, and the client/Drive workflow behind them.

## Current status
- Live. Built with Lovable — **the `main` branch is production** (live proposal and creative-session links run off it).
- Backend: Supabase (database + ~40 automated functions: emails, Drive folders, proposal reminders, Tripleseat scraping…).
- Hosted on Netlify.
